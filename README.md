# Ahmed Sharif — Engineering Portfolio

This repository contains my engineering project portfolio, documenting hands-on projects involving Arduino, sensors, embedded systems, mechanical design, and robotics.

I use these projects to develop my skills in prototyping, programming, electronics, debugging, and integrating hardware and software into complete systems.

## Projects

The portfolio currently includes:

- 8×8 Pong vs. AI
- Smart Safe
- Ultrasonic Radar
- Reaction-Time Game
- Automatic Trash Can

Each project includes a short overview of the problem, my implementation, challenges I encountered, and what I learned through the build process.

## Technologies

- Arduino Mega 2560
- C/C++
- Sensors and actuators
- Servo motors
- MAX7219 LED matrix
- Ultrasonic sensing
- Keypad input
- Analog controls
- Embedded systems prototyping

## Running the Website

The website is contained in a single `index.html` file.

To run it locally, download or clone this repository and open `index.html` in a web browser.

No installation, dependencies, or build process are required.
